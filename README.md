# Weather Intelligence App - Cloudflare Pages Deployment

## Overview
A React/Vite Weather Intelligence application generated via Google AI Studio App Build, connected to GitHub, and deployed on Cloudflare Pages.

## Tech Stack
- Frontend: React, Vite, TypeScript, Tailwind CSS, Lucide Icons
- API: Open-Meteo Geocoding and Forecast API
- CI/CD: GitHub + Cloudflare Pages

## Build Commands
- Install dependencies: `npm install`
- Development server: `npm run dev`
- Production Build: `npm run build`
- Output Directory: `dist`
